# ゲームの構成

「白衣への一年」は、理学部の生活を送りながら医学部を目指し、結果が出た後も次の一年を選べるゲームです。一週間ごとに使う時間とお金を決め、勉強・仕事・休息・人づきあいの結果を引き継ぎます。理三は特に難しく、合格だけでなく、途中の生活や関係にも遊ぶ理由を置きます。

## 一週間から一年へ

1. 体調、予定、持ち金や届いた連絡を見て、今週の時間を配分する。
2. 学習、大学、仕事、趣味、交際などを実行し、週報と出来事を読む。
3. 必要な選択を終えると、次の週へ進む。手続きや予約があるときは空き時間と費用が必要になる。
4. 出願・試験と大学の進級を経て、次の生活を選ぶ。受験結果、学習履歴、お金、家族や人間関係は続いていく。

## 暮らしと人間関係

- 家族の状況は時間とともに変わり、支援や住まいにも影響する。住まいを失っても、相談や再出発の道がある。
- 食費と睡眠は設定できる。病気や加齢も体力と学習に関わるが、負担を避けたい場合は細かい設定を変更せず進められる。
- オプチャのライブトークは週の予定に組み込む。オフ会は行き先と参加者を選び、その場の会話や後日の連絡が記録に残る。
- 出会いは希望したときに始められる。連絡の自動化も任意で、時間と費用を確認できる。
- 気持ちや人との関係の一部は直接の数値ではなく、言葉や出来事から伝える。

## お金とその後

仕事、受験用の支援、借入と学びの貸与を別に扱う。株は手動注文と任意の定期買付ができ、売買に使うお金は予定や生活費と競合する。資金を得る別の選択肢には、その後の手続きと生活への影響がある。服役中は通常の予定が止まり、家賃や借入などは時間に沿って処理する。

複雑な選択は必要な費用・時間を実行前に見せ、自動化は任意にする。細かな計算と実際の制度との差は [MODEL.md](MODEL.md) に記載する。
