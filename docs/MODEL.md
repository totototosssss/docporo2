# ゲームの数値について

このゲームは、受験と暮らしを題材にした創作です。学力、忘却、体調、模試や試験の得点、合格確率はゲーム用の計算値で、実際の学力や合否を予測するものではありません。人物の会話も創作です。

## 時間と大学

一年は48週、各月は4週、予定の1コマは3時間として扱います。実際の暦や一日の過ごし方を再現したものではありません。

理学部の授業・単位・進級は架空の仕組みです。ゲームでは、その学年の24単位以上と前後期の実験を進級条件とし、4年相当以上で条件を満たした場合に卒業を選べます。実際には、大学の修業年限は原則4年で、卒業に必要な単位数や科目などは大学の定める要件によります。大学設置基準の改正については[文部科学省の説明](https://www.mext.go.jp/content/20220930-mxt_daigakuc01-000025195_05.pdf)を参照してください。

## お金と暮らし

短期バイトの時給1,300円、塾講の時給2,000円と昇給、支援額、各週の支出はゲーム用の設定です。税金や社会保険は個別には計算していません。通常は生活費と学費を別枠の支援で簡略化し、自費の部屋では家賃を追加します。卒業後も簡略化した家計を引き継ぎます。自立した場合の実際の収支を表すものではありません。

参考として、東京都の地域別最低賃金は2026年10月1日から時給1,280円です。適用額は勤務地や時期などで異なります。最低賃金は平均的な時給を示すものではありません。［[東京労働局](https://jsite.mhlw.go.jp/tokyo-hellowork/list/kiba/minimum-wage-information_2026.html)］

## 出願と受験

共通テストの登録、私立・国公立の出願、本試験の順序は実際の制度を参考にしていますが、日程はゲーム内の週にまとめています。私立3校までという制限や、大学区分ごとの受験料・交通費はゲーム上の概算です。大学ごとの全要項・全費用を照合したものではありません。共通テストの登録費用もゲームでは計上していません。

2027年度の共通テストは、2026年9月15日から10月2日まで出願を受け付け、本試験は2027年1月16日・17日です。3教科以上の検定料は18,000円です。［[大学入試センター：出願](https://www.dnc.ac.jp/kyotsu/faq.html)、[試験日](https://www.dnc.ac.jp/kyotsu/shiken_jouhou/r9/index.html)、[検定料](https://www.dnc.ac.jp/albums/abm.php?d=753&f=abm00017382.pdf&n=%E4%BB%A4%E5%92%8C9%E5%B9%B4%E5%BA%A6%E5%A4%A7%E5%AD%A6%E5%85%A5%E5%AD%A6%E8%80%85%E9%81%B8%E6%8A%9C%E3%81%AB%E4%BF%82%E3%82%8B%E5%A4%A7%E5%AD%A6%E5%85%A5%E5%AD%A6%E5%85%B1%E9%80%9A%E3%83%86%E3%82%B9%E3%83%88%E5%AE%9F%E6%96%BD%E8%A6%81%E9%A0%85.pdf)］

合格後の入学料や医学部の授業料は計上していません。参考として、東京大学の2025年度以降の学部入学者は入学料282,000円、授業料年額642,960円です。［[東京大学](https://www.u-tokyo.ac.jp/ja/admissions/tuition-fees/e03.html)］大学や年度によって費用は異なります。

ここに挙げた実在情報は2026年11月10日時点の確認です。将来の年度の制度や日程、個別の大学・施設・商品のすべてを確認したものではありません。実際の出願には、その年度の公式要項を確認してください。

## 繰り返し測れるゲーム内ベンチマーク

Node.js 22.7以降で `node tests/benchmark.mjs` を実行すると、固定した方針で初年度から卒業後まで7年間を進め、各年の学力・共通テスト・収支・単位・状態データの大きさを JSON Lines で出力します。第1引数でシード数を1〜100、第2引数で年数を1〜50の範囲で変更できます（例：`node tests/benchmark.mjs 10 20`）。標準支援、初期装備、弱点→全科目→二次対策の順で方針を切り替え、各出願期間に候補校を1校選ぶ、限定的なシナリオです。生活・教材・学校の選び方を尽くした比較ではありません。

`selectionIndex` は個別試験の合否判定に使う内部指標です。乱数を含み、100点を超えることもあるため、100点満点の実得点ではありません。`stateJsonBytes` は状態部分を UTF-8 の JSON として測った大きさで、ブラウザの保存容量そのものではありません。出力はゲームの変更前後を比べる指標であり、実際の受験成績や家計に対する検証結果ではありません。

## 長期の出来事と資産

家族、住まい、年齢、交際、貸与、司法の出来事はゲーム上の仮定に基づきます。年齢による体力や記憶への影響は固定した個人差を含む簡略化で、個人の将来を予測するものではありません。学びの貸与は月額・利率・返済期間を設けた独自の仕組みで、実際の奨学金制度そのものではありません。

株価は共通ショックと銘柄別の変動から計算し、100株単位、売買価格の差、手数料、指値、配当を扱います。税金などは計算しておらず、実際の市場を再現または予測するものではありません。司法手続き、判決や服役期間もゲーム用に簡略化しています。
