# 白衣への一年

理学部に通いながら医学部を目指す、一年間のシミュレーション。勉強、大学の授業、仕事、休日を組み合わせて、次の春を迎えます。

## 遊び方

「一週間」で方針と時間配分を決め、週を進めます。学習室では科目や教材、大学・仕事では履修や働き方、街では休日の行き先を選べます。出願時期が来たら受験資料室で学校を選びます。

進行はブラウザに自動保存されます。別の端末やブラウザへ移る前に、設定からセーブデータを書き出してください。同じ設定画面から読み込めます。

## ローカルで動かす

ビルドや API キーは不要です。リポジトリのディレクトリで、たとえば次を実行します。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。ES modules を使っているため、HTML ファイルを直接開くと動かない場合があります。

ゲーム全体のつながりは [DESIGN.md](docs/DESIGN.md) に記載しています。

ゲームの数値の扱い、実際の制度との違い、再実行できるベンチマークは [MODEL.md](docs/MODEL.md) にまとめています。GitHub Pages への配置方法とデータの出典は [GITHUB_PAGES.md](GITHUB_PAGES.md) を参照してください。
